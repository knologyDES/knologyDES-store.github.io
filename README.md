# knologyDES — Premium Gym Wear Store

A complete responsive storefront demo for **knologyDES**, a gym apparel brand with men’s and women’s training clothes, footwear, socks, caps, bags, bottles and lifting accessories.

## Included

- 36 products across Men, Women, Shoes and Accessories
- Local product artwork for every item (no broken external image links)
- Responsive premium black / off-white / neon design
- Product search, category filters and price/name sorting
- Quick-view product modal with sizes
- Working front-end shopping cart with quantity controls and LocalStorage
- Support & fit-advice section
- Demo support phone and email placeholders
- Newsletter and advice forms ready to connect to a backend/form provider
- Mobile navigation
- GitHub Pages compatible (no build process needed)

## Run locally

Open `index.html` directly in your browser, or use any local static server.

## Publish with GitHub Pages

1. Upload all files and folders in this project to your GitHub repository.
2. In GitHub go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Save and wait for GitHub to publish the site.

## Important before going live

The support phone number `+1 (202) 555-0147` is a **demo / fictional number**. Replace it with your real business support line.

`support@knologydes.com` is a placeholder until you create and activate that mailbox.

The checkout button is intentionally a demo. Connect a real commerce/payment system such as Shopify, Stripe Checkout, Snipcart or another provider before accepting orders.

The product prices are retail prices chosen for the knologyDES catalog and aligned with current U.S. athletic-apparel price ranges. They are not copied product listings from another brand.
